## Routing table

| Domain | Sources (ordered) | Trigger |
|---|---|---|
| `bio_clinical` | PubMed + Semantic Scholar | clinical/biomedical vocabulary: protein, receptor, cell, membrane, patient, trial, gene, neuron, disease, … |
| `physics_chem` | arXiv + Semantic Scholar | physics/chemistry vocabulary: quantum, electron, photon, atom, molecule, crystal, entropy, catalyst, … |
| `math_cs` | arXiv + Semantic Scholar | math/CS vocabulary: theorem, proof, polynomial, graph, matrix, integer, algorithm, complexity, … |
| `other` | Semantic Scholar + OpenAlex | no domain keyword, or empty claim |

Rules:

* Deterministic keyword heuristic: whole-token matches, prefix match for keywords of length ≥ 6 (`protein` covers
  `proteins`). Scores are distinct keyword hits; ties resolve bio > physics > math, and physics/math share sources so
  only the bio boundary changes retrieval behaviour.
* Domain can be overridden for logging/ablation: `route_claim(claim, domain="clinical")`; unknown domains raise
  `ValueError`.
* `route_claim` returns `ClaimRoute(claim, domain, sources, signals)`; `as_dict()` is the log record.
  `Retriever.routes` appends one entry per distinct (claim, domain) so a run can persist the distribution.

## Dedup

`dedupe_results(results)` keeps the first occurrence and drops later ones sharing any identifier:

1. DOI — lowercased, `https://doi.org/`, `http://doi.org/`, `https://dx.doi.org/`, `doi:` prefixes stripped.
2. arXiv ID — new (`2501.00001`, version stripped) or old (`math.GT/0309136`) form.
3. Normalized title — lowercase, non-alphanumerics collapsed to single spaces.

PubMed now extracts `ArticleId[@IdType="doi"]`; S2 requests `externalIds` and maps `DOI`/`ArXiv`; arXiv stores the
versioned ID on the result; OpenAlex maps its DOI.

For prompt passages, `select_evidence(passages, k)` applies the same normalized-text key before taking the first `k`,
so the same paper arriving from two sources with different casing/truncation is shown once.

## Equal evidence volume

* Both partition conditions query the **same claim-routed candidate set**; `partition=True` only rotates the starting
  source per agent (the ablation from P0-8 item 5).
* `Retriever.search` tries the ordered candidates and stops once `top_k` unique results exist; if the first source is
  thin it is topped up from the remaining routed sources. A weak first source therefore cannot shrink an agent's
  evidence relative to another condition.
* `Retriever.retrieve` dedups → reranks (`top_k`) → `select_evidence(prompt_passages)`. The target volume is
  `prompt_passages` for every agent/condition; if the entire routed pool has fewer unique passages, every agent sees
  that same smaller count (honest abstention, never padding).
* Test: `test_evidence_volume_is_equal_across_partition_conditions` asserts 3/3/3 passages for agents 0–2 in both
  conditions, and distinct passage text.

## Old confound removed

`agent_source` still returns the old agent→source assignment for legacy callers/ablations, but the primary path never
uses it: `Retriever.source_names(agent_index, claim)` is driven by `route_claim`. Source now varies with the **claim**
(and only rotates with the agent when the partition ablation is enabled), so source, domain, and model family are no
longer fixed to one another.
