## CLI

```text
python scripts/verifier_audit.py make --pairs pairs.jsonl --out DIR [--format csv|jsonl]
python scripts/verifier_audit.py score --rater1 SHEET --rater2 SHEET \
    [--gold pairs.jsonl] [--pred verifier_labels.csv|jsonl] \
    [--min-kappa 0.60] [--min-balanced-accuracy 0.75]
```

**Pairs format** (JSONL, one object per line):
`{"id": "...", "claim": "...", "passages": ["..."], "gold_label": "supported|contradicted|unverifiable"}`.
`read_pairs` rejects duplicate IDs, empty claims, non-string passages and
unknown gold labels with a line/pair-specific message.

`make` writes `rater1.csv`, `rater2.csv`, `codebook.md` and `manifest.json`
(pair count + content SHA-256). Sheets carry `pair_id, claim, passages, label,
confidence, notes`; `label`, `confidence` and `notes` are blank and `gold_label`
never appears in a sheet, so the annotation stays blind. The codebook is the
protocol: label definitions, decision order (refutation first), rules (label the
claim as written, no outside knowledge, numbers and negation), the sampling plan
(150–200 pairs, ≥40 per class, 20 empty-passage negatives), the two-annotator
independence rule, adjudication, and the pass targets.

`--pred` is the verifier-scoring path: a sheet of verifier labels is scored
against `--gold` (or the human consensus when `--gold` is omitted). Without
`--gold` or `--pred` only inter-rater kappa is reported; the report says so
instead of printing a meaningless 1.0.

## Metric definitions

- **Reference:** `--gold` when given, else the rater consensus (pairs where both
  annotators agree; disagreements are counted and excluded, not hidden).
- **Prediction:** `--pred` when given, else rater 1.
- **Coverage:** share of pairs with a non-abstaining prediction
  (`label != unverifiable`). Accuracy and balanced accuracy are conditional on
  coverage, so abstention lowers coverage instead of being scored as an error.
- **Balanced accuracy:** mean per-class recall over the classes present in the
  covered reference (`supported`, `contradicted`, and `unverifiable` when it
  appears).
- **Precision / recall / F1:** macro averages plus a per-class table.
- **Confusion matrix:** always the full 3×3 over all pairs, so abstentions stay
  visible.
- **Kappa:** Cohen's κ between the two rater sheets (`eval/agreement.py`).

## Exit codes

| Code | Meaning |
|---|---|
| 0 | target met: κ ≥ 0.60 and (when metrics exist) balanced accuracy ≥ 0.75 |
| 2 | target missed |
| 1 | usage or data error (bad flags, unreadable/blank/mismatched sheets, bad JSON) |

argparse normally exits 2 on usage errors; the parser subclass maps those to 1
so 2 can mean "below target" unambiguously.

## The harness catches the lexical baseline

The synthetic set is paraphrase-heavy on purpose. Running `LexicalVerifier` over
the 20 pairs and scoring the labels against gold:

```text
> python scripts/verifier_audit.py score \
    --rater1 experiments/verifier-audit/rater1.csv \
    --rater2 experiments/verifier-audit/rater2.csv \
    --gold experiments/verifier-audit/pairs.jsonl \
    --pred results/verifier-audit-smoke/lexical-preds.jsonl
...
  "metrics": {
    "n_total": 20, "n_covered": 12, "coverage": 0.6,
    "accuracy": 0.5833, "balanced_accuracy": 0.5833, "macro_f1": 0.5556,
    "confusion": {"supported": {"supported": 5, "contradicted": 1, "unverifiable": 1},
                  "contradicted": {"supported": 4, "contradicted": 2, "unverifiable": 1},
                  "unverifiable": {"supported": 0, "contradicted": 0, "unverifiable": 6}}
  },
  "target_met": false,
  "failures": ["balanced_accuracy 0.5833 < 0.75"]
}
exit=2
```

The excerpt elides the unchanged `inter_rater`, `per_class` and `thresholds`
blocks; the quoted values are verbatim from the run, and `failures` plus the
exit code are the gate.

Concrete misses: `The Sun orbits the Earth` is called `supported` against an
Earth-orbits-Sun passage; `Penicillin promotes … synthesis` is called
`supported` against an inhibition passage; `3e8 m/s` is called `contradicted`
against `299,792,458 m/s`. This is the WP-07 argument for NLI/judge in one
table, and it shows the gate fails a verifier that is not good enough.

The prediction file above was produced offline with the verifier directly:

```text
python -c "import json; from pathlib import Path; from trustcal.retrieval.verifier import LexicalVerifier; v=LexicalVerifier(); rows=[json.loads(l) for l in Path('experiments/verifier-audit/pairs.jsonl').read_text(encoding='utf-8').splitlines() if l.strip()]; Path('results/verifier-audit-smoke/lexical-preds.jsonl').write_text(''.join(json.dumps({'pair_id': r['id'], 'claim': r['claim'], 'passages': r['passages'], 'label': v.verdict(r['claim'], r['passages']).label})+chr(10) for r in rows), encoding='utf-8')"
```

Smoke artifacts are under `trustcal/results/verifier-audit-smoke/`
(gitignored; `trustcal/results/` is the heavy-artifact location).

## Human audit protocol (ready to execute)

1. Candidate pool: SciFact dev claims plus B8 retrieval-arm claims.
2. Sample 150–200 pairs, stratified to ≥40 per label; include ~20 empty-passage
   negatives and ~20 topical-but-non-supporting passages. Record the sampling
   seed in the WP note when the real set is drawn.
3. Two annotators label every pair independently from `rater1.csv` /
   `rater2.csv`; neither sees `gold_label` or the other sheet.
4. Score with `score --gold pairs.jsonl`; discuss/adjudicate disagreements;
   record the adjudicated labels and re-run with `--pred`.
5. Report κ, balanced accuracy, per-class P/R/F1, coverage and the confusion
   matrix in the paper. Gate: κ ≥ 0.60 and balanced accuracy ≥ 0.75. If balanced
   accuracy is < 0.60 after swapping lexical → NLI/judge, stop mechanism work
   and report the negative result (03_EXPERIMENT_PLAN G1).

  a small exporter once those land. Until then the fixture is the only input.
