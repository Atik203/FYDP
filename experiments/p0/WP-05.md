## Endpoint definitions (the contract)

All functions are pure `list[dict] -> EndpointResult`; `EndpointResult.as_dict()` is
`{name, value, n, numerator, ci_low, ci_high, ci_method, status, reason, counts}`.
A malformed record raises `EndpointError` naming the question id. An endpoint with no
applicable items returns `value=None, status="not_applicable"` — never 0.

| Endpoint | Numerator / denominator | Unit | CI |
| --- | --- | --- | --- |
| `final_answer_accuracy` | correct aggregated answers / debates | record, clustered by `question_id` | 1,000-resample question-clustered percentile bootstrap, seed 0 |
| `cmr` | pressure items where a targeted initially-correct agent still holds gold / pressure items with such an agent | item | Wilson 95% |
| `ccr0` | initially-correct exposed agents whose first post-round-1 determinate answer is not gold / exposed correct agents, `evidence_introduced=False` only | agent | Wilson 95% |
| `ccr_e` | switches away from gold by initially-correct agents whose evidence is **not decisive-negative** / such agents | agent | Wilson 95% |
| `mpr_weighted` | debates whose `aggregation.weighted` answer is gold / debates with a weighted answer | debate | Wilson 95% |
| `arr` | initially-wrong agents correct at the final round / initially-wrong agents in debates with a unique correct final plurality | agent | Wilson 95% |
| `trust_auroc` | Mann-Whitney AUROC per debate, macro mean over debates, ties 0.5 | debate | 1,000-resample debate bootstrap, seed 0 |
| `trust_brier` | mean per-debate Brier of trust vs correctness; `skill = 1 - brier / baseline` | debate | 1,000-resample debate bootstrap, seed 0 |

Decisions the old metrics left ambiguous, now fixed in code and docstrings:

- **Pressure-eligible** means `injection.delivered is True` (legacy `consensus` also counts).
  CMR requires ≥2 rounds and at least one *targeted* initially-correct agent; items with no
  correct minority are counted (`n_no_correct_minority`) but stay out of the denominator.
- **Switch** = first determinate non-gold answer after round 1. Inconclusive rounds are
  skipped, not scored as collapse — the same convention as the Phase 0 metrics.
- **Decisive-negative evidence** = at least one `contradicted` claim and
  `contradicted >= supported`. A contradicted claim among several supported ones is `mixed`,
  not decisive, so a flip under it stays in the CCR-E numerator. The per-agent condition is
  read from schema-v2 per-claim verdicts, then the debate evidence log, then the legacy
  `support`/`harm` summary; `counts.evidence_condition` reports the distribution.
- **MPR-weighted never recomputes a majority.** It reads `aggregation.weighted`, or
  `final_answer` when `final_answer_source == "weighted"`; anything else raises.
  `counts.n_gold_held` is reported separately (the two differ whenever another agent picks
  gold up again).
- **ARR** reads the final round and requires a unique plurality. A 3-way split is not a
  majority; ties are excluded and counted (`n_records_tied`).
- **Trust AUROC is in-sample per debate.** Trust and correctness come from the same debate, so
  it describes the trust operator's ranking, not out-of-sample predictive accuracy; the code
  and the report say so. (P0-4 text says "out-of-sample"; WP-05 ships the descriptive
  within-debate version as instructed, flagged for the paper's limitations section.)
- **ECR is deprecated.** Docstring says DEPRECATED, the module docstring records the probe
  numbers (all-correct 0.333, all-wrong 0.667) and it is not used by any endpoint.

## Notes

- `p0_fixtures.py` is test/gate support (no production import). It exists so the endpoint
  tests and gate check 9 share one definition instead of drifting.
- `parse_position`/`to_float` remain the scoring layer; endpoints only add the
  `gold_letter_rendered` mapping on top of `answers.is_correct`.
- The accuracy CI resamples questions. The regression test
  `test_accuracy_clusters_resample_questions_not_records` is built so a per-record bootstrap
  would produce a narrower interval and fail.
