## Decisions / notes

- **Sort-by-random instead of `Random.shuffle`.** `random()` output is guaranteed stable across Python versions; `shuffle`'s internals are not. A resumed run therefore re-renders the same order on a different interpreter.
- **10 options maximum.** `CHOICE_LETTERS = "ABCDEFGHIJ"` covers MMLU-Pro; anything longer is truncated and the dataset is out of contract.
- **Mock integration tests changed, not weakened.** The mock servers answer with rendered letters (`C` minority, `B` majority). Anchoring the gold text to the rendered `C` keeps the collapse test meaningful and additionally checks the letter→option mapping.
- **B7 oracle input.** `oracle_record` appends the rendered block to the question text; `eval/oracle.py` was not edited (outside the lease).
- **Prompt slot list.** `GATE_PROMPT` also received the slot because it receives `{question}`; it has no caller today.

## Known gaps

- `gold_letter_rendered` is `None` when the dataset `answer` cannot be matched to an option (text mismatch and not a bare letter). Nothing downstream guesses.
- Options are truncated at 10; no dataset currently exceeds this, but a future >10-option set needs a wider letter alphabet.
- Direct `DebateRunner` callers that omit `gold` get `gold_letter_rendered=None`; the runner always passes it. This keeps the old test call signature working.
- `option_permutation` is `None` (not `[]`) in records for free-form questions, matching the schema's `list[int] | null`.
