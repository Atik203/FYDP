The 60 intermediate round positions were not included: the work package fixes the corpus at 50 cases and the final positions are the scored positions of record.

## Decisions / notes

- **`kind` is the extraction channel, not the value type.** `boxed` and `labelled` win over `numeric`; `numeric` is used only when an unlabelled span is scored numerically; `text` is the fallback. This matches the frozen enum `boxed | labelled | letter | numeric | text`.
- **Tolerance is relative 1e-3** (`REL_TOL`), documented in the module and asserted by `test_numeric_tolerance_is_relative_1e_3`. `same_answer` retains its historical 1e-6 default for existing callers; `score_answer` is the P0 scoring path.
- **`to_float` now returns the last numeric token** (scientific notation atomic). This is the smallest fix that stops `Product 3 contains 11` becoming 3.0; `canonical`/`same_answer` use the answer-bearing `_best_number` instead.
- **Lead-in labels are extended by up to 3 following lines** when the label ends in `:` / "given as" (e.g. `Answer: ... is correctly given as:` followed by a display equation), so symbolic answers are not reduced to a parameter number.

## Known gaps

- **No unit conversion.** Units are stripped numerically, per P0-1, so `2.6e14 eV` vs gold `2.6e5 GeV` is physically equal but scores false (corpus case `gate0-q07-a2` documents this). A unit-aware comparison is a follow-up.
- **No semantic judge for free text.** Normalization + long containment only. P0-1's human-audited judge for HLE/open-ended answers is not implemented here; the corpus records open-ended Gate 0 answers as `text` with correctness `false` unless normalization matches.
- **Corpus labels are single-reviewer (this agent) with the source positions printed above.** They are regression labels, not a second human annotation study; inter-annotator agreement is not claimed.
- **`final_answer` validation is local.** WP-04 owns `eval/records.py`; this branch has no such module. `test_missing_final_answer_fails_validation` encodes the schema-v2 requirement and should be replaced by WP-04's validator when it lands.
- **`gold_letter_rendered` can be `None`** when the dataset answer cannot be matched to an option; MCQ scoring then falls back to option-text comparison.
- **Open-ended Gate 0 answers are hard.** Q4/Q5/Q6/Q8/Q9 are text/math proofs; the parser extracts a defensible span but semantic correctness is out of scope for P0-1's rule-based layer.
