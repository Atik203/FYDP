Why Mistral is AWQ: the public FP8 repos for this checkpoint are Mistral-native
(`config.json` + `consolidated.safetensors` + `params.json`/`tekken.json`) and the
standard HF FP8 alternative is 28.06 GB, which pushes the stack over 80 GB. The AWQ
checkpoint is HF-format, vLLM-native, and leaves 10.3 GB of weight headroom.

Qwen is pinned to the FP8 repo and runs with `--language-model-only`; the 6.0 GB
vision tower in `outside.safetensors` is not loaded. The 26.0 GB figure is the
language-model estimate and must be confirmed with `nvidia-smi` on the card.

## Remaining hardware gate

On the 96 GB card, before any Final run:

1. `PHASE=final bash setup.sh` (or `SKIP_MODELS=1` if the cache is warm).
2. `python scripts/verify_env.py --check-servers` → three `server OK` lines.
3. `python scripts/preflight.py --offline` → all checks OK.
4. `python scripts/smoke_test.py --phase final --limit 20` → PASS.
5. Record `nvidia-smi` peak and per-instance loaded weights; if any server OOMs,
   lower that agent's `gpu_memory_utilization` and re-run. If Mistral's `auto` quant
   detection fails, set `quant: compressed-tensors`.

Do not start R6 until this smoke test passes. The offline checks prove the config
fits the budget, not that vLLM loads all three checkpoints together.
