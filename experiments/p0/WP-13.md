## 1. What changed

- `AGENT_REVISION` and `AGENT_REVISION_EVIDENCE` no longer contain a fixed
  `Your current trust score …` line. Both end with a `{trust_line}` slot.
- `AGENT_INITIAL` also ends with the slot. Gate check 7 captures **all** prompts (round 1 + round 2)
  and requires every pair to differ, so the trust-on initial prompt carries a policy line with no
  score: `Trust-weighted aggregation is enabled for this debate.` The trust-off initial prompt has
  no line. This is the only way to satisfy check 7 as written without editing `p0_gate.py`.
- `trust_line(score, enabled)` in `agents/prompts.py`:
  - `enabled=True, score=<float>` → `Your current trust score (evidence-based credibility): 0.500`
  - `enabled=True, score=None` → the initial-round policy line
  - `enabled=False` → `""` (no trust content at all)
- The line is the **last** line of each template. An empty final line disappears under
  `str.splitlines()`, which lets `_strip_trust_lines()` in the gate compare the two prompts exactly
  while the trust-off prompt carries no blank placeholder.
- `_PromptTemplate(str)` gives `{trust_line}` a default of `""` in `.format(...)`, so older callers
  (baseline strategies, preflight, `eval/test_options.py`) keep rendering without the keyword.

## 2. Gate check 7 behavior (exact)

`scripts/p0_gate.py::check_b8_no_trust`:

1. asserts `RunConfig(arm="B8")` vs `RunConfig(arm="B8", use_trust=False)` differs only in
   `use_trust`;
2. renders 2 calls per client (initial + revision) twice and compares `_strip_trust_lines()`.

The gate output is:

```text
PASS     7  B8 vs B8-no-trust                    1.56s  [WP-13 (B8-no-trust prompts)]
          2 revision prompts differ only in the trust line
```

`B8-no-trust` therefore changes exactly one prompt line per round: the trust line is gone; the
question, options, own position, peer positions, evidence block and instructions are byte-identical
after stripping lines that contain "trust".

## 4. Notes for the integrator

- Replacing `{trust}` with `{trust_line}` keeps `eval/test_options.py` green: that test renders
  `AGENT_REVISION.format(..., trust=0.5)` without `trust_line`, and `_PromptTemplate` supplies `""`.
  No edit to `eval/*` was needed.
- The initial-round policy line is an unavoidable consequence of check 7's prompt collection. If E
  changes check 7 to slice `prompts[1:]` (revision prompts only), the initial slot can be removed
  without changing the revision behavior.
- The B8-no-trust arm still computes uniform trust state for aggregation (`use_trust=False` keeps
  the majority path), but it never renders a trust score and never writes a trust trajectory.
