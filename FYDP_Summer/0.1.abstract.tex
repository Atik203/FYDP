	{\huge \bf Abstract}

%The abstract should contain a summary of the work presented in the report in a single paragraph. The paragraph should provide a general background of the problem, methodology and results.

Large language models can answer scientific questions fluently, and multi-agent debate can improve their reliability, but a confident wrong majority can pressure a correct minority agent into abandoning the correct answer. We call this failure sycophantic collapse; its terminal state is sycophantic consensus. Existing mitigations refine prompts, weight agents by self-reported uncertainty, or verify claims with retrieval and tools; none ties an agent's influence to claim-level external evidence during the debate. This report asks whether evidence-grounded trust reduces sycophantic collapse relative to a matched majority-vote control, and where verifier accuracy and evidence redundancy place its boundary. The framework runs three heterogeneous agents for three rounds, decomposes each response into atomic claims, routes each claim to a domain-specific source pair, assigns supported, contradicted, or unverifiable verdicts through a verifier interface, and updates a bounded trust vector through logit accumulation, one softmax, and a simplex projection; the final answer is a trust-weighted plurality. The evaluation is a pre-registered 24-run Core matrix on GPQA-Main and MMLU-Pro (primary), with HLE as a ceiling control, and a 32-row Full target with the gold-evidence oracle on EG-SSS (36 rows with the gold-answer oracle as an alternate) that adds placebo and oracle controls. External evidence is independent of an agent's self-reported confidence; B8-no-trust removes the trust signal and the trust-weighted aggregation together, and B4-matched isolates the evidence channel; two seeds, paired question-level analysis, and a pre-registered 5-point non-inferiority/7.5-point minimum detectable difference make the comparison falsifiable. The current evidence is engineering: the 13-check P0 gate passes 13/13, the suite contains 602 tests (514 at the P0 release), and Gate 0 completed 10/10 vanilla debates with 90/90 non-empty positions at a mean of 370.8 seconds. The confirmatory matrix has not run, so this report presents engineering evidence and the design of the evaluation, not an efficacy result.
