	{\huge \bf Abstract}

%The abstract should contain a summary of the work presented in the report in a single paragraph. The paragraph should provide a general background of the problem, methodology and results.

Large language models now answer hard scientific questions, yet they still hallucinate and follow broken lines of reasoning. Multi-agent debate offers one way to push back on this. Several models work through a question before committing to an answer. The reasoning usually gets sharper, and errors get caught. The real problem is how these debates settle. Most systems pick a winner by majority vote or by which agent sounds most confident. A confident majority that is simply wrong can pull a correct minority agent off its answer, and the group lands on the wrong conclusion. Current methods never check whether an agent's claims hold up against outside scientific evidence before letting that agent sway the others. This work changes how much influence each agent carries while the debate runs. Every agent response is split into small factual claims. For each claim, relevant scientific literature is retrieved and checked to see whether the evidence backs it or contradicts it. Each agent carries a trust score that moves up or down as these checks accumulate over the debate rounds. Unsupported claims lose influence, so a correct minority agent keeps its standing even when outnumbered. The final answer comes from trust-weighted aggregation, not a raw count of votes. The framework is expected to reduce hallucinations and keep reasoning tied to verifiable sources. It may also reduce premature agreement on a wrong answer while operating without model fine-tuning.
