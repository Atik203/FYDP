# Co-author templates

These are the submission formats for the TrustCal annotation sprint. Do not invent a new format; use the matching template and keep the header row unchanged.

**Guide:** [`docs/COAUTHOR_GUIDE.md`](../../COAUTHOR_GUIDE.md)  
**Repository:** <https://github.com/Atik203/trustcal>

## Naming and submission

1. Download the template, or copy it in the private folder.
2. Save a copy with your initials, using the pattern in the table.
3. Fill every row. Do not delete rows or add columns.
4. Check the row count against the batch manifest.
5. Upload the file to the private folder. Do not email or chat raw sheets.
6. Post the filename and row count in the team channel.

Author 1 copies the per-person sheets to the canonical names (`rater1.csv`, `rater2.csv`) before scoring.

## Rules

- Do not change the header row.
- Do not add extra columns.
- Do not leave a label blank. Use the exact label string from the codebook.
- Do not put names, emails, phone numbers, addresses, or payment identifiers in `notes`.
- Do not paste private claim or passage text into a public issue, a public repository, or an external AI tool.
- If you are unsure, set confidence low and write a short note.
- Ask the annotation lead before inventing a new category.
